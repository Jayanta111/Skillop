# SkilLoop Frontend

This is a [Next.js](https://nextjs.org) project bootstrapped with [`create-next-app`](https://nextjs.org/docs/pages/api-reference/create-next-app).

## Getting Started

Run the development server:

```bash
npm run dev
# or
yarn dev
# or
pnpm dev
# or
bun dev
```

Open [http://localhost:3000](http://localhost:3000) to view the application.

Edit `pages/index.js` to make changes. The page auto-updates as you edit.

## API Routes

[API routes](https://nextjs.org/docs/pages/building-your-application/routing/api-routes) are available at [http://localhost:3000/api/hello](http://localhost:3000/api/hello). Edit `pages/api/hello.js` to modify endpoints.

Files in `pages/api` are treated as API routes instead of React pages.
